# JK Form — Mobile Coach

Mobile-first MVP for personalized training, guided home workouts and meal planning based on diet preferences and selected food restrictions.

## Vercel
Deploy this repository with **Root Directory** set to `jk-form-app`.
Framework preset: **Other**. No build command or output directory is required.

## MVP note
This prototype provides general fitness and meal-planning guidance. Before a paid launch, add health screening, consent/disclaimer flows, professional review for nutrition logic, secure authentication, server-side storage and privacy controls.
